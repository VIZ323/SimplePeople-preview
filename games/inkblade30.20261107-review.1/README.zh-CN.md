# Inkblade30 · 体验还原审阅版

打开本目录的 index.html 进入真实 Cocos 游戏。按住并拖动走位，松手停步；长枪自动朝近敌出招。拾取经验后选择招式，选择与详情返回均保留真实当局。营地养成和奖励保存在当前浏览器。

此固定版本还原已验的营地、HUD、三卡和真实界面旅程，规则为六技能、两资源、三永久装备与单伙伴。当前为测试审阅版。实际内部机制样本通过至22关，第23关护送仍在验证；前30关配置不等于全部品质通过。完整倒地连续性、其余环境/敌人与伙伴动作、实体手机和音频听感仍未完成验收。

同源抖音本地测试包已构建，尚无正式AppID/IDE或真机验证。这里提供其对应远程资源；这不是正式运营发布。许可和原包声明保存在 licenses/，版本身份与资源清单见 __inkblade-source.json 和 release-manifest.json。
